# LicitatieRO approved design
Founder-built Bucharest real-estate MVP; private Github organization LicitatieRO with marketplace, infrastructure, .github repositories. Next.js/TypeScript on Vercel Pro, Supabase PostgreSQL/Auth/Storage in Frankfurt; Resend. Six physical demo properties, twelve sale/rent listings. One physical property may have both transaction types; one auction and one active reservation per property. Public ascending or sealed confidential offers; public/invite-only eligibility are separate. Server-authoritative time, serialized bids/reservations, database constraints, idempotency, authorization and RLS. No live deposits, custodial wallet, escrow claims, penalties, real-money rewards or runtime AI. Owner selects bidder after closure, simulation-only funding, refunds before external contract signing; signed tenancy enables investment sale with disclosure. Email-verified accounts, server-only Auth and protected cookies/CSRF; staff MFA; private documents and exact address. Persistent messaging/viewings/favorites and owner listing editor. RO/EN, system light/dark, responsive. CI tests/typecheck/lint/build/Playwright/database authorization and concurrency; staging and manually triggered tested-commit production deployment, isolated credentials, pinned actions, no privileged PR jobs. Docs ADR/ARD <500 / 500+ WAU, editable financial calculator, profitability uncertain, external custodian before live financial flow. Operating budget and capital constraints are maintained privately by the founder and are not part of this repository. Sites private founder hub remains a separate publication. User already approved execution; no further approval gate for routine coding, repository creation or authorized publishing.
